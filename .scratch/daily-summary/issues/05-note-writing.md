# 05 — Запись в заметку

Status: open
Blocked by: 02

Единственное место, где инструмент пишет в чужие файлы. Здесь легко незаметно
испортить рукописные заметки, поэтому **тесты пишутся до кода**.

## Задача

`app/notes/writer.py`:

- путь заметки: `notes.daily_dir` плюс `filename_format` (`%Y-%m-%d.md`);
- если `notes.daily_dir` пустой — `SummaryError` с кодом `NO_NOTES_DIR`;
- если файла нет — создать из `notes.template`, подставив дату. Шаблон содержит
  плейсхолдеры Obsidian вида `{{date:YYYY-MM-DD}}` и
  `{{date:dddd, Do of MMMM, YYYY}}`: их надо отрендерить самим, плагина рядом
  нет;
- блок вставляется между `<!-- auto:start -->` и `<!-- auto:end -->`;
- маркеров нет в файле — блок дописывается в конец;
- маркеры есть — заменяется только содержимое между ними;
- **dry-run по умолчанию**: без `--apply` функция возвращает итоговый текст и
  diff, но ничего не пишет на диск;
- запись атомарная: временный файл рядом плюс `os.replace`. Vault
  синхронизируется плагином `obsidian-git` примерно каждые 20 минут, и
  полузаписанный файл может уехать в удалённый репозиторий.

## Структура блока

```markdown
<!-- auto:start -->
## 🤖 Итоги дня

### Сделано
### Решения и обоснования
### Обсуждения
### Открытые вопросы
### План на завтра
<!-- auto:end -->
```

Пустые подсекции не выводятся. Если активности нет вообще — файл не трогается,
даже с `--apply`.

## Инварианты, которые нельзя нарушить

1. Текст вне маркеров не меняется ни на байт. Пользователь заполняет «🎯 Сегодня
   в фокусе» и «✅ На сегодня» утром руками, и галочки в его секциях инструмент
   не ставит.
2. Повторный запуск за тот же день не создаёт второй блок.
3. Без `--apply` на диске не меняется ничего.

## Готово, когда

- golden-тесты на все три инварианта, написанные до реализации;
- тест на создание файла из реального шаблона
  (`Шаблоны/Шаблон для ежедневных заметок.md`), положенного в фикстуры;
- тест, что испорченные маркеры (есть `auto:start`, нет `auto:end`) дают
  понятную ошибку, а не затирают хвост файла;
- все тесты работают на `tmp_path`, ни один не пишет в настоящий vault.
