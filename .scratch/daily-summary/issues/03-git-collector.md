# 03 — Сборщик git

Status: resolved
Blocked by: 02

Первый источник. Самый плотный по данным и единственный, где легко подорваться на
объёме.

## Задача

`app/collectors/git.py`:

- обход `git.roots` рекурсивно до `max_depth` в поиске каталогов `.git`. В
  `~/projects` сейчас 50 репозиториев, многие вложенные
  (`fm-correlation/servicefmcorrelation`, `service-fm/servicefm`);
- для каждого — коммиты в окне дня, автор по списку `git.authors`;
- на коммит: хеш, время, сообщение, список файлов, diffstat, diff;
- `include_dirty` — отдельный блок «в процессе» по незакоммиченным изменениям
  рабочей копии (`git status --porcelain` плюс diffstat);
- незапушенные коммиты учитываются наравне с запушенными.

## Лимиты

Применять в таком порядке:

1. файлы по `exclude_globs` и бинарные выкидываются до подсчёта;
2. файл длиннее `max_diff_lines_per_file` (400) — усечение с записью в
   `truncations`;
3. коммит длиннее `max_diff_lines_per_commit` (2000) — diff выбрасывается
   целиком, остаётся diffstat;
4. день длиннее `max_diff_lines_per_day` (6000) — самые большие коммиты
   деградируют до diffstat, пока не уложимся.

Почему это не опционально: за неделю до 2026-10-05 в `sma-agent` шесть коммитов
дали 3 МБ diff, из которых 2.9 МБ — один `docs/js/mermaid.min.js`, а 123 КБ —
`uv.lock`. Это около 700 тысяч токенов полностью бесполезного текста в одном
коммите «шаблон проекта».

## Детали

- вызывать `git` подпроцессом с явным `-C <repo>`, без `chdir`;
- репозиторий без коммитов, битый или недоступный — пропускаем молча, в
  `truncations` строку не пишем: это не усечение;
- не заходить внутрь `.git` вложенных репозиториев дважды: родитель и
  подкаталог считаются отдельными репозиториями, дубликаты по абсолютному пути
  отсекать;
- время коммита брать в таймзоне из конфига, иначе граница дня поедет.

## Готово, когда

- на временном репозитории, созданном `git init` в `tmp_path` с фикстурными
  коммитами, собираются ожидаемые данные. Без моков — проверяем реальный `git`;
- есть тест на каждый из четырёх лимитов, включая деградацию до diffstat;
- есть тест, что коммит чужого автора не попадает в выборку;
- прогон по реальному `~/projects` за последнюю неделю укладывается в лимит дня.
