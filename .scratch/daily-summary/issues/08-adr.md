# 08 — ADR по решениям сессии

Status: open
Blocked by: 07

Пять решений, о которые будет больно спотыкаться через полгода без записанного
«почему».

## Задача

Создать в `docs/adr/`:

### 0001 — userbot MTProto вместо Bot API

Bot API видит только группы, куда бота добавили, и не видит приватные диалоги.
Требование — «сообщения из групп и чатов», поэтому выбран userbot на Telethon.
Зафиксировать риски: серая зона правил Telegram, возможная блокировка аккаунта
при агрессивных запросах, файл сессии равносилен доступу к аккаунту. И
компенсации: только чтение, белый список чатов, rate limit, права 600.

### 0002 — сырые выгрузки вне vault

`knowledge-base` — это git-репозиторий, который плагин `obsidian-git`
автоматически коммитит и пушит в GitHub примерно каждые 20 минут. Всё, что
попадёт в vault, уезжает на удалённый хост почти сразу. Поэтому сырые дампы
живут в `~/.local/state/daily-summary/` с ретенцией 14 дней, а в vault попадает
только одобренный человеком текст.

### 0003 — маркеры вместо генерации файла целиком

Ежедневная заметка наполовину рукописная: «🎯 Сегодня в фокусе» и «✅ На сегодня»
заполняются утром человеком. Инструмент владеет только блоком между
`<!-- auto:start -->` и `<!-- auto:end -->`. Побочная выгода: будущая недельная
агрегация разбирает авто-блоки тривиально.

### 0004 — лимиты diff и двухступенчатая суммаризация

С измерением: шесть коммитов в `sma-agent` дали 3 МБ diff, из которых 2.9 МБ —
один `docs/js/mermaid.min.js` и 123 КБ — `uv.lock`. Отсюда четыре уровня лимитов
и деградация до diffstat, а также порог ~100 КБ для перехода на двухступенчатую
схему.

### 0005 — порт slop-writer вместо зависимости

Три модуля (~250 строк) портированы с атрибуцией Apache-2.0. Пакет не взят
зависимостью: тянет `mcp`, `mistune` и SQLite-схему аналитики канала, а его
`tg.py` жёстко привязан к `.tg-analytic/` в корне проекта, тогда как наше
состояние живёт в `~/.local/state/`. Отдельно отметить, какую проверку мы
намеренно не копировали: отказ от сущности `User`.

## Что сюда не входит

`CONTEXT.md` не создаём. `docs/agents/domain.md` прямо требует создавать
глоссарий лениво, когда термины реально устоятся. Сейчас ещё не ясно,
называется это «источник» или «сборщик», — вернёмся после первой рабочей версии.

## Готово, когда

- пять ADR на месте, каждый с контекстом, решением, отброшенными альтернативами
  и последствиями;
- ADR 0004 содержит конкретные числа измерения, а не общие слова.
