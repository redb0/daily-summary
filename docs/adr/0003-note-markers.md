# Маркеры вместо генерации файла целиком

Status: accepted

## Контекст

Ежедневная заметка наполовину рукописная. «🎯 Сегодня в фокусе» и «✅ На сегодня» человек заполняет утром. Инструмент этим текстом не владеет.

## Решение

Инструмент пишет только блок между `<!-- auto:start -->` и `<!-- auto:end -->`. Повторный запуск заменяет содержимое между маркерами. Заметки за день нет — файл создаётся из шаблона. Активности нет — файл не трогается.

## Отброшенные альтернативы

Генерировать файл заметки целиком. Утренние разделы затирались бы при каждой записи.

## Последствия

Текст снаружи маркеров остаётся. Если маркеров в файле ещё нет, блок дописывается в конец вместе с ними; следующий запуск обновляет уже только внутренность. Есть `<!-- auto:start -->` и нет `<!-- auto:end -->` — ошибка `BROKEN_MARKERS`, файл не переписывается. Один `<!-- auto:end -->` без старта пару не ломает: блок дописывается в конец. Недельная агрегация, когда до неё дойдёт очередь, вырезает авто-блоки по тем же маркерам.
