# Сырые выгрузки вне vault

Status: accepted

Раскладка одного `YYYY-MM-DD.json` заменена [ADR-0006](0006-dump-per-source.md). Вне vault, права и ретенция 14 дней остаются.

## Контекст

`knowledge-base` — git-репозиторий. Плагин `obsidian-git` коммитит его и пушит на GitHub примерно каждые 20 минут. Файл, записанный в vault, почти сразу оказывается на удалённом хосте.

## Решение

Сырые дампы лежат в `~/.local/state/day-recap/raw/YYYY-MM-DD.json`, права 600, ретенция 14 дней. В vault попадает только текст, который человек подтвердил: `day-recap write --apply`. Сессия Telethon лежит в том же каталоге состояния.

## Отброшенные альтернативы

Класть дампы рядом с ежедневными заметками. Переписка, diff и черновики уехали бы в GitHub вместе с vault.

## Последствия

Вчерашний день можно пересобрать, пока дамп не старше 14 дней. Без `--apply` vault не меняется.
