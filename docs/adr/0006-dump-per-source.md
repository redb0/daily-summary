# Дамп на каждый источник

Status: accepted

День хранится каталогом `raw/YYYY-MM-DD/` с файлами `git.json`, `transcripts.json`, `opencode.json`, `telegram.json`. У каждого дампа своё окно. Полный сбор пишет все четыре файла, сбор одного источника переписывает только его файл. Нет файла — источник несобранный. `show` старый `raw/YYYY-MM-DD.json` не читает.

Один JSON на день оставлял одно окно на все источники. После вечернего повтора git это окно врало либо про коммиты, либо про чаты. Читать старый файл четырнадцать дней значило бы держать второй разборщик ради одного уже лежащего дампа: день проще собрать заново.

Вне vault, права 600 и ретенция 14 дней остаются как в ADR-0002. Ретенция удаляет и каталог дня, и оставшийся одиночный JSON, не читая его.
